# Spector: Universal Anti-Cybercrime & Threat Intelligence Engine

A cloud-based real-time security dashboard designed to detect and analyze modern cyber threats like phishing, malware, and financial scams.

## 🚀 Live Demo
Aap yahan project ko live test kar sakte hain: [Click Here to Open App](https://spector-soc-dashboard-bwij6fegedvlcmmrjwaghw.streamlit.app/)

## 🛡️ Key Features
- **Phishing Detection:** Analyzes suspicious links for tunneling services (like Ngrok) and credential harvesting patterns.
- **Malware Scanner:** Detects dangerous file extensions.
- **Crypto Fraud Alert:** Identifies patterns related to modern financial/crypto scams.
- **Incident Response:** Provides step-by-step playbooks for users under attack.

## 🛠️ Tech Stack
- **Frontend/Dashboard:** Python (Streamlit)
- **Deployment:** Streamlit Community Cloud
- **Logic:** Custom Heuristic Patterns & Regex Analysis

## 💡 How to use?
1. Open the Live Demo link.
2. Paste any suspicious link, domain, or filename in the input box.
3. View the forensic analysis and security recommendations.ools to democratize threat intelligence and secure endpoints against external credential-harvesting matrices.
